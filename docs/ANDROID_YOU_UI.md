# You and preferences UI — controlled PWA import

Use the PWA profile summary and local tools as the reference. Present identity, workout goal, saved-session count and rolling seven-day goal progress in a tonal profile panel. Group routine, preference and schedule navigation as native list items; keep support and data maintenance visually separate. Routine navigation opens the existing library.

Backup status and import/export stay visible. Expand migration instructions on request, preserve document pickers and import review, and explain that backups exclude active workouts. Retain active-draft import guards, pending-save disabling, reviewed reset/clear actions and their existing messages.

Preferences use a compact heading, grouped tonal controls and an explicit save action. Preserve name validation, goal/range validation, RPE retention, interaction preferences, durable editing, warning confirmation and epoch/revision conflict handling. At large text sizes, summary metrics and paired rep-range fields stack. No settings values or persistence contracts change.
