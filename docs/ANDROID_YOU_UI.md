# Profile and settings UI

Profile replaces the former combined You/settings page. Match the PWA identity, training goal, logged-session count and weekly progress hierarchy. The small header settings icon opens Settings. Routines and backup/data stay available as short profile shortcuts; preference controls and data maintenance are not inline on Profile.

Settings presents a conventional scrolling form with short labels and grouped controls. Name, goal, RPE, weekly schedule, haptics/animations and data/support links remain available. Progression defaults expand on request; Save changes appears for unsaved edits. Retain validation, warning review, explicit save, dirty Back confirmation, restoration and revision/epoch fences. Unchanged editors refresh on return from secondary pages without reloading over edited values.

Backup/data is a separate page with the existing status, document pickers, import review, pending-save/draft guards and reviewed reset/clear actions. No persistence or backup contract changes. See [current structure](ANDROID_PROFILE_SETTINGS_UI.md).
